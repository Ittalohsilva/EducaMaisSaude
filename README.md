# Educa+ Saúde

**Aprenda a cuidar melhor da sua saúde.**

Projeto desenvolvido para a disciplina de Desenvolvimento de Aplicações Web.

## Sobre o projeto

O Educa+ Saúde é uma aplicação web voltada para educação em saúde. A página
apresenta conteúdos educativos de forma simples e organizada, com uma Hero
Section, categorias de saúde, dicas e um formulário de cadastro.

O tema inicial era Educação, mas foi adaptado para Saúde, mantendo o nome
Educa+.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub

## Funcionalidades

- Cabeçalho com menu de navegação
- Hero Section com slogan e botão "Começar agora"
- Cards de categorias: alimentação saudável, atividade física, sono e descanso, prevenção
- Lista de dicas de saúde
- Formulário de cadastro com validação
- Mensagem de confirmação ao enviar o formulário
- Rolagem suave ao clicar nos links do menu

## Estrutura do projeto

- index.html
- styles.css
- script.js
- README.md

## Layout e responsividade

- HTML semântico com header, nav, main, section, article e footer
- CSS externo no arquivo styles.css
- Flexbox no cabeçalho e na Hero Section
- Grid na área de categorias
- Layout responsivo com media query para telas menores

## Acessibilidade

- Link "Pular para o conteúdo principal" para navegação por teclado
- Foco visível nos elementos interativos
- Atributos aria-label, aria-hidden e role="status" com aria-live
- Rótulos associados a todos os campos do formulário
- Bom contraste entre texto e fundo

## Como executar

1. Baixe os arquivos do projeto.
2. Abra o arquivo index.html em qualquer navegador.
