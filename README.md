# educa-mais-saude

Aprenda a cuidar melhor da sua saúde. Projeto desenvolvido para a disciplina de Desenvolvimento de Aplicações Web.

## 🏥 Educa+ Saúde

### 📍 Cenário do Projeto

O **Educa+ Saúde** é uma aplicação web voltada para educação em saúde. A página apresenta conteúdos educativos de forma simples e organizada, com uma Hero Section, categorias de saúde, dicas e um formulário de cadastro.

O tema inicial era Educação, mas foi adaptado para Saúde, mantendo o nome Educa+.

---

### 🛠️ Tecnologias e Ferramentas Utilizadas

* **HTML5:** Estrutura semântica com header, nav, main, section, article e footer.
* **CSS3:** Estilização externa (`styles.css`), Flexbox no cabeçalho/Hero, Grid em categorias e responsividade com media queries.
* **JavaScript:** Lógica de navegação com rolagem suave e validação de formulário com mensagem de confirmação.
* **Acessibilidade:** Navegação por teclado (pular conteúdo), foco visível, contraste e atributos ARIA (`aria-label`, `aria-hidden`, `role="status"`).
* **GitHub:** Controle de versão e hospedagem do repositório.

---

### 📁 Estrutura de Arquivos no Repositório

* `index.html` : Contém a estrutura principal e semântica do projeto.
* `styles.css` : Folha de estilo responsável pelo layout e responsividade.
* `script.js` : Scripts de interatividade e validação do formulário.
* `README.md` : Documentação do projeto.
